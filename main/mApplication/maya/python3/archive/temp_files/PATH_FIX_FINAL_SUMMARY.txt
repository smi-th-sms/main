 WHAT WAS FIXED

User Reported Issue:
--------------------
"경로상에 앞부분에 ../가 더 추가되어야 해 경로를 제대로 못찾고 있어"

Problem:
--------
Paths used ../ (one level up) instead of ../../ (two levels up)

Root Cause:
-----------
object_merge2 is a SOP node INSIDE Cache geo node, not at obj level:
  /obj/assets/Cache (geo node)
  └── object_merge2 (SOP node)  ← needs ../../ to reach /obj/assets

Solution:
---------
Changed ALL paths from:
  ../Proxy/geo_{name}/OUT_{name}_PROXY
To:
  ../../Proxy/geo_{name}/OUT_{name}_PROXY

================================================================================
 TECHNICAL DETAILS
================================================================================

Path Structure Understanding:
------------------------------
object_merge2 location: /obj/assets/Cache/object_merge2 (SOP level)
Target location: /obj/assets/Proxy/geo_X/OUT_X_PROXY

Navigation:
  SOP (object_merge2) 
  → ../ → Geo (Cache) 
  → ../ → Obj (assets) 
  → Proxy/ → Geo (Proxy) 
  → geo_X/ → Geo 
  → OUT_X_PROXY (SOP target)

Required path: ../../Proxy/geo_X/OUT_X_PROXY

Why Two Levels:
---------------
1. First ../: SOP level → Geo level (Cache)
2. Second ../: Geo level → Obj level (assets)
3. Then: Navigate down to target

Common Mistake:
---------------
Assuming Cache is at obj level:
  /obj/Cache/object_merge2  ← WRONG
  
Actual structure:
  /obj/assets/Cache/object_merge2  ← CORRECT
  (Cache is a geo node inside assets)
